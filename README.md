# gigacheck_skill

A Claude Code skill for detecting whether **English or Russian** text was written by a human or generated by an AI model, using **GigaCheck-Classifier-Multi** (Mistral-7B).

The model is loaded via the **Transformers API** (`trust_remote_code=True`).

## What this skill does

**gigacheck_skill** lets Claude Code classify text as **AI-generated** or **human-written** with high accuracy.

Under the hood it runs:
1. **Language detection** — rejects unsupported languages (only EN and RU are supported)
2. **Token truncation** — processes first 1024 tokens (model limit)
3. **GigaCheck-Classifier-Multi** — Mistral-7B based binary classifier

**Key capabilities:**
- Single text string, file, or batch folder processing
- Strict language guard — refuses non-English/non-Russian text with a clear error
- GPU + CPU support — auto-detects available hardware
- Isolated environment — installed in its own `.venv`, no system Python impact
- Returns structured JSON with label, confidence, language and token count

> ⚠️ **Language restriction:** only **English** and **Russian** texts are supported. Other languages are rejected.

```bash
git clone https://github.com/iitolstykh/gigacheck_skill
cd gigacheck_skill
claude
```

Then type `/setup` — Claude will automatically install all dependencies, create a virtual environment, and register the skill globally.

After setup, just ask from **any** Claude Code session:
```
Check if this text is AI-generated: [paste your text here]
```

The model (~14GB for Mistral-7B) downloads automatically on first run.

## Installation

### Automatic via `/setup` (recommended)

```bash
git clone https://github.com/iitolstykh/gigacheck_skill
cd gigacheck_skill
claude
# Type: /setup
```

The `/setup` command will:
1. Check that **Python 3.11** is installed
2. Create an isolated **virtual environment** at `.venv/`
3. Install all dependencies (PyTorch, Transformers, GigaCheck, langdetect)
4. Register the skill in `~/.claude/skills/` so it's available globally
5. Verify the installation

### For Claude Code (manual)

**Option A — via npx + cp:**
```bash
# 1. Install via npx
npx skills add /path/to/gigacheck_skill
# or from GitHub:
npx skills add https://github.com/iitolstykh/gigacheck_skill

# 2. Copy to Claude Code skills directory
cp -r ~/.agents/skills/gigacheck_skill ~/.claude/skills/gigacheck_skill

# 3. Install dependencies
cd ~/.claude/skills/gigacheck_skill && bash install.sh
```

**Option B — manually:**
```bash
cp -r /path/to/gigacheck_skill ~/.claude/skills/gigacheck_skill
cd ~/.claude/skills/gigacheck_skill && bash install.sh
```

Restart Claude Code — it will pick up the skill automatically.

### For other agents (Cursor, Codex, Gemini CLI, etc.)

```bash
npx skills add https://github.com/iitolstykh/gigacheck_skill
```

This installs to `~/.agents/skills/gigacheck_skill` and runs `install.sh` automatically.

## Model

### [iitolstykh/GigaCheck-Classifier-Multi](https://huggingface.co/iitolstykh/GigaCheck-Classifier-Multi)

Multilingual binary classifier (EN + RU) for AI-generated text detection.

| Metric | Score |
|--------|-------|
| F1 Score (AI) | 98.64% |
| F1 Score (Human) | 98.00% |
| Mean Accuracy | 98.46% |
| TPR @ FPR=0.01 | 97.93% |

- Base model: **Mistral-7B-v0.3** with LoRA fine-tuning
- Size: ~14GB
- Trained on: English and Russian portions of the LLMTrace Classification dataset
- Max input: **1024 tokens** (longer texts are truncated)
- Loaded via: `AutoModel.from_pretrained(..., trust_remote_code=True)`

> ⚠️ Performance may degrade on text from LLMs released after September 2025.

---

## Pipeline

```
Text → Language detection (EN/RU only)
     → Normalize newlines
     → Truncate to 1024 tokens
     → GigaCheck-Classifier-Multi
     → label: AI / human + confidence
```

## Usage

### From Claude Code

Simply ask Claude in natural language:
```
Check if this text is AI-generated: [paste text here]
```
```
Is this article written by a human or AI? [paste text]
```
```
Classify all .txt files in ./documents/ as human or AI-written
```
```
Check document.txt — was it written by a person?
```

### CLI

```bash
SKILL_DIR="$HOME/.claude/skills/gigacheck_skill"

# Single text string
$SKILL_DIR/.venv/bin/python $SKILL_DIR/gigacheck_inference.py \
  --text "Artificial intelligence is transforming many industries."

# Text file
$SKILL_DIR/.venv/bin/python $SKILL_DIR/gigacheck_inference.py \
  --file essay.txt

# Batch folder
$SKILL_DIR/.venv/bin/python $SKILL_DIR/gigacheck_inference.py \
  --folder ./documents/

# Force CPU
$SKILL_DIR/.venv/bin/python $SKILL_DIR/gigacheck_inference.py \
  --text "..." --device cpu
```

| Argument | Required | Description |
|----------|----------|-------------|
| `--text` | One of three | Raw text string to classify |
| `--file` | One of three | Path to a `.txt` file |
| `--folder` | One of three | Path to folder with `.txt` files |
| `--device` | No | `cuda` (default if available) or `cpu` |

## Examples

### Single text

```bash
$SKILL_DIR/.venv/bin/python $SKILL_DIR/gigacheck_inference.py \
  --text "Искусственный интеллект меняет многие отрасли промышленности."
```
```json
{
  "label": "AI",
  "confidence": 0.9923,
  "language": "ru",
  "tokens_used": 12
}
```

### Text file

```bash
$SKILL_DIR/.venv/bin/python $SKILL_DIR/gigacheck_inference.py --file essay.txt
```
```json
{
  "label": "human",
  "confidence": 0.9871,
  "language": "en",
  "tokens_used": 1024
}
```

### Batch folder

```bash
$SKILL_DIR/.venv/bin/python $SKILL_DIR/gigacheck_inference.py --folder ./documents/
```
```json
{
  "doc1.txt": {"label": "human", "confidence": 0.9871, "language": "ru", "tokens_used": 856},
  "doc2.txt": {"label": "AI", "confidence": 0.9945, "language": "en", "tokens_used": 1024},
  "doc3.txt": {"label": "human", "confidence": 0.9412, "language": "en", "tokens_used": 342}
}
```

### Unsupported language

```bash
$SKILL_DIR/.venv/bin/python $SKILL_DIR/gigacheck_inference.py --text "Bonjour le monde"
```
```json
{
  "error": "unsupported_language",
  "detected_language": "fr",
  "message": "Detected language 'fr' is not supported. GigaCheck-Classifier-Multi only supports English ('en') and Russian ('ru')."
}
```

## Output format

```json
{
  "label": "AI",
  "confidence": 0.9923,
  "language": "en",
  "tokens_used": 512
}
```

| Field | Type | Description |
|-------|------|-------------|
| `label` | string | `"AI"` or `"human"` |
| `confidence` | float | Prediction confidence (0–1) |
| `language` | string | Detected language (`"en"` or `"ru"`) |
| `tokens_used` | int | Number of tokens processed (max 1024) |
