# GigaCheck Skill — AI vs Human Text Detection

Classify whether **English or Russian** text was written by a human or generated by an AI model.

- **F1 Score (AI):** 98.64%
- **F1 Score (Human):** 98.00%
- **Mean Accuracy:** 98.46%
- **Model:** [iitolstykh/GigaCheck-Classifier-Multi](https://huggingface.co/iitolstykh/GigaCheck-Classifier-Multi)

> ⚠️ **Language restriction:** This skill only processes **English** or **Russian** text. For any other language, refuse and explain that the model does not support it.

## Auto-setup

Before first use, check if the virtual environment exists. If not, install automatically:

```bash
SKILL_DIR="$(cd "$(dirname "$(readlink -f "$0")" 2>/dev/null || echo "$0")/../" && pwd)"
[ -d "$SKILL_DIR/.venv" ] || SKILL_DIR="$HOME/.claude/skills/gigacheck_skill"
[ -d "$SKILL_DIR/.venv" ] || bash "$SKILL_DIR/install.sh"
```

Models (~14GB for Mistral-7B) are downloaded from HuggingFace automatically on the first inference run and cached in `~/.cache/huggingface/`.

## Usage

```bash
SKILL_DIR="$HOME/.claude/skills/gigacheck_skill"

# Classify a text string directly
$SKILL_DIR/.venv/bin/python $SKILL_DIR/gigacheck_inference.py --text "Your text here"

# Classify text from a file
$SKILL_DIR/.venv/bin/python $SKILL_DIR/gigacheck_inference.py --file document.txt

# Batch: classify all .txt files in a folder
$SKILL_DIR/.venv/bin/python $SKILL_DIR/gigacheck_inference.py --folder ./texts/

# Force CPU (slower, no GPU required)
$SKILL_DIR/.venv/bin/python $SKILL_DIR/gigacheck_inference.py --text "..." --device cpu
```

### Arguments

| Argument | Required | Description |
|----------|----------|-------------|
| `--text` | One of three | Raw text string to classify |
| `--file` | One of three | Path to a `.txt` file |
| `--folder` | One of three | Path to a folder with `.txt` files |
| `--device` | No | `cuda` (default if available) or `cpu` |

### Output format

Returns JSON to stdout:

```json
{
  "label": "AI",
  "confidence": 0.9923,
  "language": "en",
  "tokens_used": 512
}
```

Or for batch (folder):

```json
{
  "document1.txt": {"label": "human", "confidence": 0.9871, "language": "ru", "tokens_used": 1024},
  "document2.txt": {"label": "AI", "confidence": 0.9945, "language": "en", "tokens_used": 768}
}
```

## Installation

### Quick install (Claude Code)

```bash
git clone https://github.com/iitolstykh/gigacheck_skill
cd gigacheck_skill
claude
# Type: /setup
```

### Manual install

```bash
cp -r /path/to/gigacheck_skill ~/.claude/skills/gigacheck_skill
cd ~/.claude/skills/gigacheck_skill && bash install.sh
```
